# M2 financial research review packet

This packet contains invented development disclosures and candidate claims with provisional developer-checked labels. It is **not human verified**, a genuine filing corpus or an untouched holdout. No research-quality scores have been calculated. Automated regression assertions are not human labels.

The protocol fixes proposed thresholds and metric denominators before held-out evaluation. It is separate from strategy/promotion EP-1 policies and grants no publication/trading permission. A human must approve the protocol, verify source facts and availability independently, fill expected fields/outcomes/reasons, identify the reviewer and review timestamp, resolve disagreements, and freeze the approved reference hash. Null/unknown labels, missing approvals or zero denominators produce unavailable results, never passing quality acceptance.

For each case, verify source identity/revision, reporting period, scope, literal value, unit/currency, normalization, exact cited passage and analysis availability. Record the source-derived reference, not agreement with the proposed claim or model confidence. Include missing, conflicting, wrong-entity, wrong-unit, fabricated citation and future-disclosure cases in a separately authored holdout. The initial ten development cases are not sufficient coverage or sample size for acceptance.

Do not use these known development cases as the final holdout or tune against the holdout after freezing it. No second LLM can mark this packet human verified. Existing D3-11 split/holdout controls must govern the eventual evaluation run; no parallel experiment framework is introduced here.

The ten development cases now have provisional labels (one supported and nine requiring rejection). Their provenance explicitly says developer-checked; reviewer identity/approval and human verification remain unset. `M2-heldout-registration.json` is an empty registration template, not a fabricated human-verified set.

`M2-actual-local-development.json` records two actual installed-model calls on an invented two-row disclosure, including the first rejected output and the second prompt version. These are development observations, not held-out scores or proof of general filing accuracy. No human-verified research-quality metrics are available.
