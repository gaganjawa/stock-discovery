# STK-020 — Calendars and corporate actions

Versioned session calendars exclude non-session dates and require calendar availability at the analysis cutoff. Corporate actions carry versioned provenance/effective times. Split price features apply only known, effective splits and preserve raw candles; dividends do not silently become price adjustments. Duplicate adjustments/actions fail closed. Volume windows and simulated trades crossing actions must be excluded until full share/cash entitlement handling is implemented. Real exchange imports are blocked by provider access/rights.

Validation: focused calendar/split cases pass for holiday gaps, future or late action knowledge, raw-price preservation and calendar availability. This is synthetic feature normalization, not a full corporate-action trading simulator.

Status: Partial; calendar import boundary and split features implemented. Real calendar import and full action execution remain blocked/deferred and must be disclosed at release.
