# STK-044 — Synthetic batch inspection and export

Status: Ready for Release for synthetic scope. Private release remains blocked by STK-018.

Existing bounded batch requests enqueue persistent, idempotent jobs for each selected date/instrument. The dashboard now offers authenticated job inspection with job ID, status, attempts, sanitized error code, dataset/cutoff/instrument inputs and resulting recommendation IDs. Details can be refreshed. Missing jobs return 404. Errors retain their exception class only, without exception messages or credentials.

Audit JSON now includes all jobs, including queued/running/failed records, alongside frozen decisions, run manifests, outcomes and scorecard exclusions. Recommendation IDs link completed jobs to versioned run IDs and outcomes. Export is limited to the existing synthetic repository; no real-market export permission is inferred. The dashboard still lists the latest 20 jobs; the authenticated job endpoint accepts any known ID and the export retains all jobs.

Malformed batch dates are rejected before enqueue; calendar validation and the existing batch transaction prevent partial scheduling. New scan, replay and batch requests include server code, strategy and configuration versions in job identity. Same-version requests reuse job IDs; submitting after an upgrade creates separate jobs and preserves old results. Workers reject mismatching pins through bounded retries with ExecutionVersionMismatch. Legacy unpinned queued jobs retain their previous current-worker behavior. Deployments must set an immutable CODE_VERSION; local-unversioned cannot distinguish local edits. Arbitrary historical code execution is not supported.

Validation: 50 local application tests passed; 9 database cases deferred to CI. Frontend build passed. Extended browser acceptance runs nine sample jobs, inspects details, downloads JSON and verifies job-to-decision/run/outcome links. Database acceptance exercises exhausted retries, failure details/export retention and missing-job handling. Implementation `ae607b2` passed [full CI](https://github.com/gaganjawa/stock-discovery/actions/runs/38551308960), including the nine-job browser/export workflow and database failure-drill-down tests.
