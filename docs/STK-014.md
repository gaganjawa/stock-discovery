# STK-014 — Shared availability-aware adapters

Implemented historical/live clocks, typed market/document/account interfaces and an immutable synthetic adapter. All timestamps require timezone offsets. Eligibility checks publication, availability, retrieval and closed-bar time; only verified archives or explicitly fictional fixtures may be reconstructed after the cutoff. Live mode requires actual retrieval by cutoff. Duplicate candle identities require a pinned revision before use. No real provider or order capability is enabled.

Validation: 13 unit tests pass; 4 PostgreSQL integration tests skipped without a database. Focused cases cover cutoff boundaries, late revisions, live fetch timing, malformed OHLC, nonfinite prices, naive timestamps, duplicate candles and matching document/account cutoff semantics. Existing contracts and synthetic examples unchanged.

Status: Ready for Release pending M1 integration and private release. Real provider access/rights remain unresolved. Account/document interfaces are boundaries, not broker integrations.
