# STK-022 — Synthetic historical ingestion

Content-addressed synthetic datasets persist raw candles, source revisions and a complete immutable manifest (identities, mapping history, membership, sessions and actions). Transactional page checkpoints support repeat/restart without duplicate candles; configurable bounded page size and inter-page delay. Same provider revision with conflicting values fails rather than overwriting history. Real network imports, provider rate limits and permission-dependent APIs remain disabled.

Validation: deterministic demo and as-of tests pass; PostgreSQL ingestion of 300 fictional daily candles repeated without duplicates. Immutable manifest and conflicting checkpoint configuration rejection pass. Five database integration cases plus upgrade/downgrade/re-upgrade and atomic failure rollback pass. Status: Ready for Release, synthetic scope.
