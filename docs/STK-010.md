# STK-010 — Repository and application setup

Status: **Done**
Priority: P1 · Release: v0.1

This ticket establishes the smallest local, synthetic-only foundation agreed in S04:

- a React and TypeScript web shell;
- a FastAPI API with a health check and one deterministic demo response;
- one Python worker capable of an explicit scheduled loop or a one-shot synthetic cycle;
- one shared Python analysis package used by both API and worker;
- a reserved PostgreSQL migration layout; and
- Docker Compose services for the web shell, API, worker and PostgreSQL.

No schema is introduced (STK-013), no product navigation is introduced (STK-011), and no market-data, broker, LLM or account integration is enabled. All responses are synthetic and explicitly non-actionable.

Validation completed before commit:

- `pytest` ran three targeted API/worker tests successfully.
- The worker completed one synthetic cycle successfully.
- A temporary local FastAPI server returned successful `/healthz` and `/api/v1/demo/recommendation` responses.
- The React/TypeScript production build succeeded.
- `compose.yaml` passed structural validation. This host's Docker installation does not provide the Compose subcommand, so containers were not started here.
- All existing STK-001, STK-002 and STK-003 fixture validators still pass.
