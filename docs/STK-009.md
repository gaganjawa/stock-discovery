## Obligations and compatibility

| Licence family / examples | Attribution and redistribution conditions |
|---|---|
| MIT / React, Vite, FastAPI, fancy-canvas | Retain copyright and permission text with copies/substantial portions. No copyleft source-release requirement from MIT alone. |
| ISC, BSD-2/3-Clause / many JS utilities, Uvicorn, HTTPX | Retain copyright, conditions and disclaimer; observe BSD non-endorsement clauses where present. |
| Apache-2.0 / Charts, TypeScript, Playwright; packaging alternative | Include full licence and applicable NOTICE; retain attribution, identify modifications if made, observe patent/termination terms. No trademark endorsement rights inferred. |
| 0BSD / embedded tslib | Permissive; upstream Microsoft copyright and full text retained despite no notice condition in 0BSD. |
| PSF-2.0 / Python, typing-extensions; greenlet mixed MIT/PSF | Retain applicable Python/PSF notices and modification summaries where applicable. Python's composite licence includes historical terms; full text retained. |
| CC-BY-4.0 / caniuse-lite 1.0.30001815 | Build-time browser support data: retain creator attribution, licence link and change indication if adapted. No modified dataset here. Not found in browser runtime graph. See [official deed](https://creativecommons.org/licenses/by/4.0/). |
| MPL-2.0 / certifi 2026.7.22 | File-level copyleft: redistribution requires covered-source availability and notices; modifications to covered files remain MPL. Private internal use differs from distribution. See [Mozilla FAQ](https://www.mozilla.org/en-US/MPL/2.0/FAQ/). |
| LGPLv3 / psycopg and psycopg-binary 3.2.10 | Preserve LGPL and incorporated GPL terms; conveying a combined work introduces source/relinking or suitable shared-library mechanism and reverse-engineering conditions. A wheel's licence label does not clear bundled libraries. Full installed LGPL text retained in Python notices; source/offer/GPL packaging must be checked before image distribution. |
| GPL/LGPL and exceptions / OS packages | Private execution does not by itself require publication of the application. Conveying images/binaries can require corresponding source, licence texts and applicable exceptions; do not assume a Docker image is a single permissive work. Debian GCC copyright records cover GPL and runtime exceptions; libxcrypt includes LGPL2.1+ and per-file terms; consult retained text rather than flattening to one SPDX ID. |
| PostgreSQL / server and libpq | Preserve copyright, permission and disclaimer. Runtime server declaration recorded; exact server/bundled libpq notice/source package completeness remains a distribution gate. |
| UNKNOWN or mixed native components | No inferred grant. Resolve before distributing or enabling the affected platform/artifact. |
